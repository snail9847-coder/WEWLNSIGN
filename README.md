# WEWLNSIGN

Простой статический сайт для подписи и установки `.ipa` на iPhone.

## Что умеет

- Загрузка `.ipa` файлом (выбор или drag-and-drop) либо по прямой ссылке.
- Пошаговое отображение процесса подписи с прогресс-баром.
- Счётчик 7-дневного срока действия бесплатной подписи с датой окончания.
- Список приложений с кнопками «Переподписать сейчас» и «Установить».
- Адаптация под iPhone, светлая и тёмная темы.

## Как работает подпись

Подпись выполняет сам iPhone сертификатом вашего Apple ID через установщик
SideStore или AltStore. Сайт только передаёт IPA в установщик:

- Ссылка на IPA → открывается `sidestore://install?url=…` или `altstore://install?url=…`.
- Локальный файл → системное меню «Поделиться» → выбираете установщик.

Никакие пароли, сертификаты и файлы никуда не отправляются: всё хранится
только в браузере (`localStorage`) и на самом устройстве.

Каждые 7 дней достаточно открыть сайт и нажать «Переподписать сейчас» —
установщик заново подпишет приложение вашим сертификатом Apple ID.

## Состав

- `index.html` — весь сайт (HTML + CSS + JS, без зависимостей).
- `icon.svg` — иконка сайта.
- `vercel.json` — конфигурация статического деплоя.

## Локальный запуск

Откройте `index.html` в браузере или запустите:

```
python3 -m http.server 8000
```

## Деплой на Vercel

1. https://vercel.com/new → импортируйте этот репозиторий.
2. Framework Preset: **Other**, Build Command: пусто, Output Directory: `./`.
3. Deploy.
