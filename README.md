# WEWLNSIGN

Простой сайт для загрузки `.ipa` файлов, подписи сертификатом Apple ID и установки приложений на iPhone.

## Возможности

- Загрузка любого `.ipa` файла с устройства
- Подключение сертификата Apple ID, который используется для установки
- Отображение процесса подписи и установки по шагам
- Информация о сроке действия подписи (7 дней) и дате окончания
- Кнопка повторной подписи/установки каждые 7 дней
- Адаптивный дизайн под iPhone, светлая и тёмная тема

## Состав проекта

```
index.html    весь сайт (HTML + CSS + JS, без зависимостей)
icon.svg      иконка проекта / аватарка
vercel.json   настройки статического деплоя на Vercel
```

## Локальный запуск

Откройте `index.html` в браузере. Сборка не требуется.

## Деплой на Vercel

1. Откройте https://vercel.com/new
2. Выберите репозиторий `WEWLNSIGN`
3. Framework Preset: **Other**, Build Command: пусто, Output Directory: `./`
4. Нажмите **Deploy**

## Подключение сертификата подписи

В `index.html` задайте адрес своего сервиса подписи:

```js
var SIGN_ENDPOINT = "https://your-signing-service";
```

Пока переменная пустая, сайт работает в демо-режиме: показывает весь процесс подписи,
сроки действия и список приложений. После указания адреса кнопка «Установить» открывает
установку на iPhone по ссылке `itms-services`.

Срок действия бесплатной подписи Apple ID — 7 дней, поэтому приложение нужно
подписывать заново через раздел «Мои приложения».
